## Changes by finding

All edits are confined to `docs/assets/src/`, `tests/visual/` and this report.

1. **Write destinations (P1).** `inventory.py` gains `is_plain_filename` (ASCII `[A-Za-z0-9][A-Za-z0-9_-]*` with dotted suffixes, no `..`, no separators, no leading dot) applied to every output and source path. `pipeline.run` now aborts after the global checks whenever an `inventory`/`arguments` error exists, adding `aborting before any renderer runs: N declaration error(s) above`, so no renderer is called and nothing is written. `_asset_dir_problem` refuses a `docs/assets` that is a symlink or resolves anywhere other than `<root>/docs/assets`. `_contained_target` is evaluated immediately before each write/compare: the name is re-validated, a symlink at the target is refused, and an existing target must resolve to a regular file whose parent is the resolved asset directory. Regressions: `test_invalid_declarations_abort_before_any_renderer_runs` (renderer call count stays 0, no `docs/escaped.svg`, no sibling output written, both modes), `test_symlinked_output_is_never_followed` (outside file unchanged in write mode; refused in check mode), `test_symlinked_asset_directory_is_refused`, plus `is_plain_filename` parametrized cases.
2. **Archive binding (P1).** `tools.verified_binary` no longer reads receipts. Archive artifacts require the pinned archive to be retained in the cache (`cached_archive_path`); verification re-hashes that archive against the manifest pin, re-extracts the pinned member (`tools.extract_member`, moved from `setup_tools.py` and hardened against bad archives) and compares the member bytes with the cached executable byte for byte. `setup_tools.install_binary` now writes the archive beside the member and records `archive_retained` in the receipt, which is a record only. No new pins were introduced. Regressions: forged executable with a coherent forged receipt and no archive; retained archive not matching the pin; pinned archive present but executable differing from the member; correct pair passes with the receipt deleted; archive corrupted after a successful verification; tar.gz path; `extract_member` none/two/unsupported/corrupt cases; `install_binary` end to end without network.
3. **README references (P2).** `references.py` scans whole-file text (line numbers computed from offsets), parses double-quoted, single-quoted and unquoted HTML attributes across lines, and classifies each target: `local`; `same-repo` (`raw.githubusercontent.com/ajaysurya1221/actseal/<ref>/<path>` and `github.com/ajaysurya1221/actseal/{blob,raw}/<ref>/<path>`, mapped to the repository path); `badge` (allowlist: `img.shields.io`, this repository's `actions/workflows/*/badge.svg`, `results.pre-commit.ci/badge/`); otherwise `external`, which is an error. Local and same-repo targets must exist, be a declared output and belong to an implemented asset. Nothing is fetched. Regressions: missing same-repo absolute asset; existing file of an unimplemented figure (unit and pipeline level); unrecognized external URL and another repository's raw URL; badge exemption; single-quoted/unquoted/multiline parsing; classification table.
4. **Alt text (P2).** `Reference.needs_alt` is true for Markdown images and `<img>`, false for `<source srcset>`. Missing, empty or whitespace alt is `has no alt text`. Regressions cover all four forms and the `<picture>` exemption.
5. **Decoded resource syntax (P2).** Decoded attribute values are whitespace-stripped and lower-cased, then scanned for `url(`, `javascript:`, `@import`, `@font-face`, `http:`, `https:`, `data:`, `file:`, `ftp:`. Decoded element text and tails are scanned for the CSS/script subset (`url(`, `javascript:`, `@import`, `@font-face`) so prose such as "data: 128 cases" stays legal. Raw-text checks for declarations and processing instructions are preserved. Regressions: `u&#114;l(…)`, hex references, spaced `U R L(`, encoded `javascript:` and `https:` in attributes; encoded `url(` and `@import` in `<desc>`; prose schemes allowed.
6. **Text size (P2).** `_parse_px` returns `None` unless the value is finite and positive; an invalid `font-size` on any element is reported where it appears and does not inherit. `transform_scale` parses a transform list: `translate`/`rotate` preserve lengths, `scale` and `matrix` contribute their smallest axis factor, non-finite or zero factors and skews/unparsable syntax are errors. The factor accumulates through ancestors and multiplies the rendered label size. Regressions: `NaN`, `inf`, `-inf`, `0`, `-12`, `1e400`; direct `scale(0.01)`, anisotropic scale, `matrix`, mixed list; nested ancestor scales; length-preserving transforms pass; skew/NaN/zero/wrong arity/garbage rejected; helper values.
7. **Recording times (P2).** `_cast_seconds` rejects bools, non-numbers, JSON `NaN`/`Infinity`, values that overflow `float`, and negatives. v2 absolute times must be non-decreasing (`timestamp 30.0 precedes previous 100.0`); v3 accumulation must stay finite (`accumulated time overflowed to inf`). Regressions for every case across both versions.
8. **Provenance.** This report.

Documentation under `docs/assets/src/README.md` and `NOTICES.md` now describes containment, reference classification, decoded-token checks, transform-aware sizing, recording time rules and retained-archive verification.
