## Intentional 0.1 -> 1.0 breaks

1. Lock schema 1 -> 2 with required final `replay_engine_version` in the seal;
   0.1.0 locks are `LegacySchemaError` with pinned-replay guidance.
2. Manifest schema 1 -> 2 (also versions contained record encoding); 0.1.0
   bundles replay as ERROR `integrity.legacy_schema` (exit 3) with guidance.
3. `validate_lock` admits approved compatible implementations (dual
   registration) instead of exact source only; collection remains exact-source
   and is now guarded in `collect()` and `verify_run` before any provider work.
4. Every CLI JSON receipt carries `schema_version: 1`; `lock --json` adds
   `replay_engine_version`; `replay --json` adds `notes`.
5. Abbreviated long options rejected on every subcommand.
6. `records.SCHEMA_VERSION` meaning narrowed to the contract TOML version;
   `CONTRACT_SCHEMA_VERSION`/`LOCK_SCHEMA_VERSION`/`BUNDLE_SCHEMA_VERSION`/
   `RECEIPT_SCHEMA_VERSION` added.
7. New module `actseal.compatibility` and packaged registry file.

allocation, verdict precedence, six faults, provider protocol/constructors,
