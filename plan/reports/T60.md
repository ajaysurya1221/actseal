## Deviations from spec (with reason)

1. **No `tests/acceptance/conftest.py`.** Shared helpers live in
   `tests/acceptance/acceptance_support.py`. Under pytest's default prepend import
   mode a second `conftest` module would replace `sys.modules["conftest"]`, and the
   existing unit tests import `from conftest import ...`; a second conftest would
   therefore break the shared default suite. The task allows acceptance-only
   helpers under the owned directory.
2. **Own wheel/venv fixtures instead of importing `tests/packaging/test_wheel.py`.**
   `uv run --frozen pytest tests/acceptance` runs without `tests/packaging` on
   `sys.path`, so importing those helpers would fail at collection. The preparation
   steps are repeated (build, fresh venv outside the checkout, `--no-deps --offline`);
   the assertions are different (guarded real-path isolation, documented command
   shapes, all four exit codes through both entrypoints, guarded fixture runs).
3. **Dynamic-code guards are installed after `import actseal.cli`, network and
   prohibited-import guards before it.** Dataclass construction and the import
   system itself call the builtin `exec`; denying it before import makes the
   interpreter unusable rather than proving anything about bundle data. The guarded
   window still covers every input/bundle byte (processed only inside `main()`), and
   the test asserts zero recorded attempts.
4. **Consistent-regression BLOCK test patches `assessment.evaluate` as well as
   `faults.evaluate`.** This is a test seam (monkeypatch), not a product branch. It
   exists to show the documented "correctly reconstructed fault that violates its
   expected action is BLOCK" path; the primary follow-up test leaves the assessor
   unpatched and asserts ERROR `integrity.fault_decision`, as the dispatch requires.
5. **Coherent same-lock rewrite is asserted only as the ADR 0005 boundary.** The test
   proves the external lock digest catches it and that without an anchor it replays
   as a different experiment; no stronger provenance guarantee is asserted.
6. **README currently carries no quickstart command.** The documented-command check
   reads both `README.md` and `docs/quickstart.md`; the demo command is found in
   `docs/quickstart.md`. If root later adds README quickstart commands, the same test
   validates them against installed `--help` automatically.
7. **Expected-status corrections during authoring were to my own arithmetic, not to
   the product.** Two draft expectations (28/30 coverage under a 0.99 limit; 0/9
   accepted under a 0.5 coverage limit) were wrong; the oracle showed INCONCLUSIVE and
   BLOCK respectively, matching the product. The tests now derive those expectations
   from the independent oracle. No product behavior was adjusted to or by any test.
