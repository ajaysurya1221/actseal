## Deviations

1. **No downloads performed.** Every `curl` invocation (piped and single-command forms, GitHub release API) was denied by the permission controls; I did not retry through another tool. Consequently `docs/assets/src/fonts/` and `receipts/` do not exist yet and `--check` reports the fonts and binaries as `not fetched` at `[info]` level. Binary download URLs in `tools.toml` follow upstream release naming at the pinned tags but were not confirmed in this session; the SHA-256 pins from the approved audit remain the authority and `setup_tools.py` refuses to install on mismatch.
2. **`tests/visual/__init__.py`.** Other test directories are not packages. The pre-commit command `mypy --strict src/actseal tests` rejects a second `conftest.py` (and a `test_cli.py`) as duplicate module names; making `tests/visual` a package gives its modules unique names without touching pyproject or the hook.
3. **Interface superset.** `--only` may be repeated; `setup_tools.py` is a second, explicitly separate entry point for the network-bound setup. `render.py` itself matches the contract exactly.
4. **fontTools has no `source_commit`.** The audit pinned it by wheel hash, not commit; the manifest allows an empty commit only for `kind = "python"` and the check verifies the hash against `uv.lock` instead.
5. **OFL.txt is verified by content markers plus the setup receipt**, not a pre-pinned digest, because the audit did not record that file's hash. The font files themselves are hash-pinned.
6. **Provisional declarations.** Figure heights for Tasks 12–18 and the label-size display width (880 CSS px, documented as an assumption to be confirmed by the ten-second screenshot) are placeholders the implementing tasks finalize in `inventory.py`.
7. Implementation was done directly by Fable 5.1 rather than delegated, following the dispatch and AGENTS.md "do not substitute models" over the general routing preference.
