## Changes by finding

All edits are confined to `docs/assets/src/` and `tests/visual/` plus this report.

1. **Prerequisite errors block execution and writes (P2).** `pipeline.BLOCKING_SCOPES` now covers `inventory`, `arguments`, `manifest` and `fonts`. Any error in those scopes from the global checks aborts before any asset is processed, so no renderer or tool runs and nothing is written; the abort line names the offending scopes. Unfetched fonts/binaries stay `[info]` unless an implemented asset needs them, in which case that asset alone is skipped with an error (unchanged). Reference and orphan errors are reported but deliberately do not block, otherwise a figure the README already cites could never be written the first time; that choice is documented in code and README. Regressions: wrong pinned font bytes (write and check modes: zero renderer calls, nothing written, `checked`/`written` empty); correct font bytes allow rendering; `uv.lock` pin mismatch blocks; invalid manifest entry blocks; unfetched fonts remain informational with no implemented need; a README reference error does not block the first write and the following check passes.
2. **No image reference is silently skipped (P2).** `references.py` now uses `html.parser.HTMLParser` (stdlib, `convert_charrefs=True`), so a quoted `>` inside an attribute, single quotes, unquoted values, entities and multi-line tags parse correctly. `<img src>`, `<img srcset>` and `<source srcset>` are all inspected. Markdown reference images `![alt][label]`, `![alt][]` and `![alt]` resolve against `[label]: target` definitions (case-insensitive, `<target>` form accepted); an unresolved label is an error. `<img>` without `src`, and `<object>`, `<embed>`, `<iframe>`, `<video>` are rejected as unsupported image syntax. Every reference increments the inspected count; a `problem` set at scan time is always an error. Regressions: the three reviewer probes (`alt="Freeze > Run"`, `<img srcset=… alt=…>`, `![Figure][diagram]` with definition) each now report the missing file; collapsed/shortcut/unresolved labels; unsupported tags; `<img>` without `src`; entity decoding.
3. **Badges need alt text (P2).** Alt is checked before the badge exemption, which now exempts only the file check. `<img src="https://img.shields.io/pypi/v/actseal.svg">` and `![](https://img.shields.io/...)` fail with `has no alt text`; `<source>` stays alt-exempt. The exempt-badge test now expects two inspected references, zero errors.
4. **CSS escapes (P2).** Any backslash in any attribute value is rejected (`contains a backslash; CSS escapes are not allowed in attribute values`), as the review preferred over interpreting CSS. Regressions: the two exact probes `\75rl(//example.invalid/p.svg#paint)` and `u\72l(remote.svg#paint)`, plus `url\(x)` and a trailing backslash; an ordinary document with hex/`rgb()`/`currentColor` paints, path data, quoted font stacks and Unicode text passes with no errors.
5. **Matrix scale (P2).** `minimum_singular_value(a, b, c, d)` returns the exact smallest singular value of the linear part, computed as `|det| / sigma_max` for stability near singularity, with 0 for singular matrices. `transform_scale` uses it for `matrix(...)`; a zero result is `degenerate transform`. Regressions: helper values including the reviewer's near-singular case (old column-norm estimate 1.0, correct value about 0.0007); `matrix(1 0 1 0 0 0)` on text and on an ancestor is degenerate; `matrix(1 0 1 0.001 0 0)` on 28 px text (direct and ancestor) renders at 0.0 px and fails; anisotropic `matrix(1 0 0 0.02 0 0)` fails; a rotation matrix keeps size and passes.

`docs/assets/src/README.md` describes the blocking scopes, the HTML/Markdown parsing and the backslash and singular-value rules.
