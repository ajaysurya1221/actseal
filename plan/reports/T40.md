Deviations from spec (with reason)

- Canonical byte form is enforced on read as well as write: `lock.json`,
  `verdict.json`, `manifest.json` and every row of `records.jsonl`/
  `faults.jsonl` must re-encode to exactly the stored bytes (sorted keys,
  compact separators, ensure_ascii=False, one terminal LF). The contract fixes
  canonical bytes as deterministic and forbids schema repair; accepting
  equivalent non-canonical encodings would admit multiple byte forms of one
  bundle. Raw datasets are never subjected to this; they are exact raw bytes.
- `write_bundle` refuses evidence whose fresh assessment carries any
  `integrity.*` reason, even when the stored verdict honestly records that
  ERROR. The honest runner cannot produce such evidence, and sealing
  non-reproducing records would create a replayable but worthless bundle. The
  complete ADR 0009 infrastructure ERROR is written unchanged.
- Existing-destination refusal raises `FileExistsError` (errno EEXIST, no path
  in the message) and unsupported platform/symbol raises `NotImplementedError`;
  the frozen exception hierarchy has no better fit and errors.py is frozen.
  Native syscall failures propagate as `OSError` with the reported errno.
- The published directory keeps `mkdtemp`'s 0o700 mode (files 0o644). Raw
  bodies may contain sensitive data and generated runs are ignored by default;
  a different published mode is a Codex/T50 decision.
- Reason-code vocabulary added within the frozen `integrity.<invariant>` family:
  `bundle_io`, `bundle_schema`, `bundle_hash`, `lock_schema`, `expected_lock`,
  `inputs`, `records_schema`, `faults_schema`, `verdict_schema`, `verdict`;
  `integrity.lock` and all assessment codes are reused from `assessment.py`
  constants rather than re-spelled. Stage order is fail-fast per stage
  (structure, lock decoding, identity, decoding, semantics); codes accumulate
  within the identity and decoding stages.
- Symlink/nonregular checks use `lstat`/`scandir` immediately before the
  bounded `read_input_text` read (which follows symlinks). ADR 0012 places a
  hostile process mutating the bundle during replay outside the trust model;
  a file that grows between inspection and read is still rejected by the
  bounded limit (tested).
- `read_bundle_files`, `decode_rows` and `decode_document` are exposed
  submodule helpers so replay stages stay separable; no package-root
  re-export was added (`__init__.py` is T00-owned).
