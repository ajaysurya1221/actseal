(Apple M5 Pro, 24 GB), and which datasets the comparison can use.

## Questions to answer, with evidence

1. Laya: does the pinned native stack (`uv run --frozen --extra laya …`) run a
   decision locally? Throughput (cases per minute) and peak memory.
2. Jev-compatible local serving: can Clef (9B base) or any other open-weight
   decision model be served locally behind a Jev-compatible endpoint? For each
   candidate: source URL, licence, download size, whether it loads in 24 GB,
   throughput, and whether a request built by
   `actseal.experimental.providers.jev.request_body` is answered in the shape
   the Jev normaliser accepts.
3. Determinism: are 20 repeated identical requests byte-identical per model?
4. Datasets: two or three public classification datasets with at most 16
   labels, at least 3,000 labelled examples, and a licence that permits
   redistribution. Record licence URL and label count for each. Prefer intent
   or routing tasks.
5. Estimate wall-clock time for the comparison: models × datasets × about
   1,500 cases each.

## Rules

- Downloaded files are untrusted data: keep each in its own directory, never
  execute code from a model repository beyond the documented loader, and do not
  run install scripts piped from the network.
- Stop a download that would exceed 20 GB for one model, or 60 GB in total.
- **Another session on this machine is using Ollama** (human's note, 13 Nov
  2026). Do not stop, restart, reconfigure or upgrade the Ollama server. Do not
  unload, delete or overwrite any existing Ollama model. Do not load a model
  through Ollama while it is serving someone else; prefer a separate server
  process on its own port for spike models.
- Load one spike model at a time and unload it before the next. Before each
  load, check free memory; if less than 10 GB is free, wait or skip and record
  it. Run at low priority (`nice`) and never run two inference jobs at once.
- Never read or print `.env` values, tokens or credentials.
- A denied command stays denied: record it and continue.
