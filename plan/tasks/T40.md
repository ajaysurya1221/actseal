## Interface contract (frozen)

`write_bundle(bundle: EvidenceBundle, destination: Path) -> Path` in evidence.py; `replay(bundle: Path, *, expected_lock_sha256: str | None = None) -> Verdict` in replay.py. All schemas/limits are CONTRACTS §6 and amended §2: generic bounded JSON128MiB, each JSONL record1MiB, lock32MiB, aggregate bundle128MiB, nesting32 and at most10,000 cases per split. Use the exact manifest object `{schema_version: 1, files: {filename: {size: int, sha256: str}}, sha256: str}`; the self hash excludes only the manifest's own sha256. No unknown entries or schema repair.

The exact seven filenames are manifest.json, lock.json, calibration.jsonl, verification.jsonl, records.jsonl, faults.jsonl and verdict.json. Manifest inventories the other six. Serialize canonical JSON plus specified LF; preserve raw dataset bytes. No timestamps, host paths, durations, PIDs or credentials in sealed data. The lock's current implementation identity is enforced, not migrated silently.

Replay imports only pure records/serialization/contracts/locking/normalization/policy/fault-capture/assessment logic; never load an adapter, optional dependency, bundle module, restored environment or live provider. Reconstruct each request from locked cases, check request hashes and canonical fault captures, re-normalize and re-evaluate, recompute assess, and compare every stored result with its reconstruction before returning a verdict.

## Acceptance criteria (testable)

1. A valid EvidenceBundle writes byte-identically across independent new destination roots; input objects/files remain unchanged. Existing destinations are never overwritten. Sibling-temporary-directory construction and atomic rename leave no purported completed partial bundle after a write failure.
2. Read/write paths reject symlinks, nonregular files, extra/missing files, traversal/absolute/unsupported manifest names, duplicate keys, malformed metadata, unknown schemas, oversized rows/files/lock/aggregate and excess nesting. Validate sizes before reading unbounded content.
3. Replay freshly computes every semantic layer and returns the expected actual verdict. Stored normalization/action/verdict changes, swapped request hashes, missing/duplicate/reordered cases, omitted/swapped fault scenarios and changed labels produce ERROR even when ordinary file and manifest hashes are recomputed.
4. Wrong external lock digest, self-seal, dataset inventory or current implementation fingerprint produces ERROR. Correctly recorded nonfatal provider failures remain complete denominator observations with their prescribed policy action (unknown_choice is DENY). A malformed recorded body is not automatically damaged outer bundle structure. Regular Laya timeout/unavailable instead yields diagnostic ERROR after all integrity checks: infrastructure.worker_invalidated, zero counts and [0,1] intervals, while preserving every terminal record. Synthetic campaign failures do not trigger this rule.
5. Replay runs in a subprocess with optional provider imports and network access denied and never executes bundle content. Error paths are bounded and do not echo sensitive source values. Document in REPORT that a wholly rewritten consistent bundle cannot authenticate itself; tests must not assert otherwise.
