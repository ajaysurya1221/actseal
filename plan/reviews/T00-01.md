## Findings ordered by severity; required changes

1. **P1 — Linux optional runtime violates the OSS constraint.** PyPI Torch pulls
   CUDA/NVIDIA packages including nvidia-cublas 13.1.1.3 with
   LicenseRef-NVIDIA-Proprietary. Use the exact platform-conditional CPU pins and
   explicit index in docs/dependencies.md. Published Linux dependency metadata
   must require +cpu so pip cannot silently choose CUDA. Regenerate uv.lock,
   confirm CUDA/NVIDIA/Triton nodes disappear, preserve the tested macOS wheel.
   This is a mandatory release correction, not an optional optimization.
2. **P2 — Invalid normalized answers and verdicts pass direct construction.**
   ChoiceAnswer accepts total mass 0 or 2; ModelIdentity accepts unsupported
   providers; Verdict accepts PASS with zero cases/accepted cases. Enforce the
   now-explicit local invariants in CONTRACTS §1 in both direct/wire paths.
   Root independently reproduced all four invalid acceptances. Add regression
   tests without weakening any existing acceptance assertions.
3. **P2 — Schema exceptions and diagnostics are inconsistent.** GateLimits with
   10**400 raises bare OverflowError. strict_json_loads accepts an escaped
   unpaired-surrogate object key; canonical_json on that key raises bare
   UnicodeEncodeError. canonical_json(10**5000) raises bare ValueError. A bad
   value under an arbitrary key exposes that key in SchemaError diagnostics.
   Validate Unicode keys as well as values, use positional paths for untrusted
   keys, and translate conversion/encoding errors to value-free SchemaError.
   Root independently reproduced each issue with synthetic values, no secrets.
4. **P2 — Generic parser limit cannot support full locks.** Apply the recorded
   pre-acceptance amendment: generic strict_json_loads ceiling 128 MiB/depth 32;
   downstream JSONL readers enforce 1 MiB rows and lock reader 32 MiB. Add boundary
   coverage including an aggregate object above 1 MiB. Do not allocate a giant
   model or weaken the bounded parsing contract.
5. **P2 — Source distribution lacks required reproducibility material.** Include
   uv.lock and README explicitly and ensure LICENSE/NOTICE are in release files.
   After Codex integrates the current docs, build from sdist and inspect actual
   contents. Hatchling force-includes license files when present; this review
   does not falsely claim that its default licensing behavior omits them.
