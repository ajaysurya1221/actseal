## Interface contract (frozen)

Exactly the records, constructor field order, aliases, error classes and
serialization functions specified in plan/CONTRACTS.md sections 1–2. No signature
changes, hidden defaults or additional runtime dependencies. PlanLock includes
verification_cases. All direct constructors validate; strict deserialization is
not the only validation boundary. Defensive conversion must prevent mutable
aliases while preserving type checks and rejecting strings used as sequences.
Records/schema_version support only version 1. Canonicalization accepts JSON
values only; unknown arbitrary objects are errors. Discriminated Outcome round
trips without arbitrary imports. Schema errors disclose paths, not input values.

## Acceptance criteria (testable)

1. An editable install imports actseal with no Laya/Torch/Transformers installed.
   Package version 0.1.0, Python >=3.12, stdlib runtime core, Hatchling backend.
2. Every public record round-trips canonical JSON. Reject unknown/missing fields,
   duplicate keys at every level, unsupported versions, wrong enums, bool numbers,
   nonfinite numbers, invalid hashes, depth >32 and raw JSON >128 MiB. Apply coherent
   local invariants (counts, intervals, label uniqueness, capture exclusivity).
3. Mutation of caller-owned lists/maps never mutates a constructed record. Frozen
   children are recursively immutable. Tuples serialize as arrays; key maps are
   sorted and unique. Constructors and from_data enforce the same domains.
4. implementation_fingerprint reads package source bytes without execution and
   is stable across directory roots, ignoring pycache and unrelated files.
5. uv.lock resolves the verified tool pins; the default environment has no live
   stack. Add optional `laya` extra pinned to the exact six native versions from
   docs/dependencies.md, only if resolution succeeds; report conflicts rather
   than silently changing pins. Support Linux/macOS Python3.12/3.13.
