## Corrections to the original REPORT T60

- **Oracle terminology.** The original report called the helper an "independent exact
  Clopper-Pearson oracle". It is an independent oracle that evaluates the exact binomial
  formula in floating point and bisects; agreement with the product is asserted to 1e-9,
  not exactly.
- **Same-lock terminology.** The original report described a "coherent same-lock
  rewrite". That test reseals a changed lock (gold label, inventory digest, raw dataset
  hash); the lock digest changes and the external anchor catches it. The eight forgeries
  that genuinely keep the lock seal unchanged are the ones in
  `test_same_lock_forgeries_error_even_without_an_external_anchor`.
- **No-target-read claims.** The original names and summary claimed targets were "never
  read" / rejected "before reading"; the assertions only showed the reason code. The
  corrected tests instrument this with unreadable targets so the single
  `integrity.bundle_schema` reason now does distinguish "not opened" from "opened and
  failed" (when the test process is not root), and the names state that behavior.
- **README observation.** The statement that `README.md` carried no quickstart command was
  true at base `434c682`. Current `main` now includes a quickstart, to be integrated before
  final CI; `test_documented_command_shapes_match_the_installed_cli` reads both `README.md`
  and `docs/quickstart.md` and will validate the integrated README commands against the
  installed `--help` without further change.
- **Pre-commit coverage.** The original report noted the hooks saw only tracked files; the
  acceptance files are tracked at the candidate, so this corrective hook run did cover them.
