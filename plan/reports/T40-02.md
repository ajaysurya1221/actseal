- `src/actseal/evidence.py` (modified; +160/-42 lines)

     rejects a non-`Path` or any path whose `os.fspath` contains `\x00` with
     `SchemaError("<field>: must not contain NUL")` (the message never echoes

     with `remaining` and `charge(size)`; `charge` raises
     `SchemaError("bundle: aggregate size exceeds <limit> bytes")` before any
     bytes are retained. `_encode_files(bundle, limit)` now threads one budget
     through the seven files in bundle order: lock document (incl. LF), raw
     calibration bytes, raw verification bytes, each records row (row + LF,
     charged per row immediately after its 1 MiB row check), each faults row,
     verdict document and finally the manifest (incl. LF). Encoding stops at
     the first overflowing row or file; later rows/files are never serialized
     and no oversized join is made. `_encode_dataset` additionally rejects
     text whose character count (a lower bound on UTF-8 bytes) already exceeds
     the remaining budget before allocating the encoded copy. Row/lock/dataset

     module-level `MAX_BUNDLE_BYTES` at call time; the full-size default is
     the frozen 128 MiB ceiling, manifest and every LF included.
  3. **Finding 3 (unbounded directory inventory).** New `_inventory(bundle)`
     iterates `os.scandir` and raises `SchemaError` at the first entry whose
     name is outside the seven-name set or already seen, without exhausting
     the iterator or retaining more than seven entries; after a fully valid
     listing it reports missing names. `_inspect` uses it; symlink/nonregular/
     size/aggregate checks and the no-content-before-validation property are

Deviations from spec (with reason)

- NUL-path rejection uses `SchemaError` (argument misuse) in the writer,
  helper, reader and replay. The frozen exception hierarchy has no closer
  fit; a `ValueError` from `os.lstat` would otherwise escape `replay`, which
  must return a Verdict or SchemaError (ADR 0012).
- The aggregate budget overflow error names the active limit
  (`bundle: aggregate size exceeds <limit> bytes`), so instrumented
  small-budget tests can assert the exact ceiling; the default limit is the
  frozen 128 MiB and the message text for real callers is unchanged.
- Encoding order under the budget is lock, calibration, verification,
  records, faults, verdict, manifest. The manifest is charged last because
  its bytes depend on the other six; its size is therefore the only amount
  checked after the six files exist, and by then the six files are already
  known to fit the ceiling, so no multi-gigabyte materialization is possible.
- `replay.py` was touched only for the NUL argument check (reason above); no
  verdict-authority logic changed.
- All earlier accepted implementation choices (canonical-on-read, exposed
  submodule helpers, writer refusing non-reproducing evidence, 0o700 directory
  mode) are unchanged.
